Passo 2: consultar pedidos do período de repasse vigente

Realizar GET no endpoint https://api.omnik.io/v1/financial/cycle/registers?transferDate=YYYY-MM-DD&isCurrent=true 

curl --location 'https://api.omnik.io/v1/financial/cycle/registers?transferDate=2025-07-08&isCurrent=true' \
--header 'token: f59a949d-5c65-4783-801b-7a0d00f3202d' \
--header 'application_id: 9605993459' \
--header 'seller: YSKY97446016589275' \
--header 'Content-Type: application/json'

Onde "YYYY-MM-DD" correspondem à data consultada no passo 1. 

Buscar os dados retornados em "marketplaceId" quando o campo "type" for igual a "SALE".

Passo 3: Consultar detalhes do pedido

GET https://api.omnik.io/HUB/v1/orders/marketplaceid/{pedido} 

curl --location 'https://api.omnik.io/HUB/v1/orders/marketplaceid/1532291799464-01' \
--header 'token: f59a949d-5c65-4783-801b-7a0d00f3202d' \
--header 'application_id: 9605993459' \
--header 'seller: YSKY97446016589275' \
--header 'Content-Type: application/json'

Onde "pedido" é o marketplaceId do pedido consultado no passo 2.
